Tu as déjà Wilson sur un autre appareil ? Inutile de tout ressaisir : sur cet autre appareil, ouvre les réglages (appui long sur le visage) → « Copier mes réglages sur un autre appareil », puis scanne le code avec l'appareil photo de celui-ci.
